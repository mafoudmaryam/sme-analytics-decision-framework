# Preliminary research questions

**Status:** Proposed; subject to refinement after the broader literature review.

| Question | Proposed evidence | Boundary on interpretation |
| --- | --- | --- |
| How can SMEs evaluate the expected value of different analytics projects? | Comparison of published approaches; source-linked criteria; explicit assessment assumptions | Expected value is a prospective judgement, not observed financial return |
| How sensitive are project rankings to the weighting of evaluation criteria? | Controlled weight variation; rank agreement; top-choice switches; threshold analysis | Sensitivity describes the model and inputs tested, not all SMEs |
| Can a lightweight decision-support framework improve the consistency and transparency of analytics project selection? | A predefined comparison with an unstructured selection task, if human evaluation is feasible; rationale traceability audit | Deterministic repeatability alone cannot show improved human decisions |

## Working definitions

- **Analytics project:** A bounded initiative intended to use data analysis to support a business activity or decision.
- **Expected value:** Anticipated benefits considered alongside effort, feasibility, and risk; not necessarily a monetary expected-value calculation.
- **Ranking sensitivity:** The extent to which changing specified assumptions changes project ordering or the preferred project.
- **Consistency:** Agreement across assessors or repeated comparable decisions, measured separately from software repeatability.
- **Transparency:** The ability to trace a recommendation to inputs, scoring rules, weights, and stated assumptions.
- **Lightweight:** Intended to require modest data, software, and user effort. Acceptable thresholds must be defined and evaluated before this becomes a performance claim.

No question has been empirically answered by this project.
