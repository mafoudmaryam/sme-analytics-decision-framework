# Evaluating Analytics Project Selection Frameworks for Small and Medium-Sized Enterprises

**In Progress — Started November 2026**  
**Researcher:** [Maryam Mafoud](https://github.com/mafoudmaryam)  
**Academic background:** Fourth-year Software Engineering student, Sichuan University, China  
**Research areas:** Management Information Systems; Business Analytics; SME Digital Transformation; Decision Support Systems.

## Overview

This independent research project will examine how small and medium-sized enterprises (SMEs) can compare potential analytics projects using explicit evaluation criteria. It will investigate how changes in criterion weights affect project rankings and whether a lightweight decision-support approach can make selection decisions more consistent and transparent.

The project is at the proposal and initial literature-review stage. **No framework has been implemented or validated, no dataset has been collected or generated, and no experiments or interviews have been conducted. There are no research results or project publications.** The materials here document a proposed direction, not completed achievements. This is a personal research project; the affiliation above identifies academic background and does not imply university endorsement.

## Preliminary research questions

1. How can SMEs evaluate the expected value of different analytics projects?
2. How sensitive are project rankings to the weighting of evaluation criteria?
3. Can a lightweight decision-support framework improve the consistency and transparency of analytics project selection?

## Proposed approach

- Extend the initial literature review and establish the project's scope and comparison methods.
- Specify a traceable set of candidate criteria, scoring rules, and weight assumptions.
- Develop a small, reproducible decision-support prototype after the specification is reviewed.
- Use explicitly labelled hypothetical scenarios to examine ranking behaviour and sensitivity.
- Consider a separate practitioner evaluation only if access, consent, and applicable ethics requirements can be satisfied.

Scenario experiments could establish computational behaviour; they would not establish business value, real-world effectiveness, or general applicability to SMEs.

## Initial literature

Langer and Pütterich (2024), *Assessing Value Creation of Analytics Projects in SMEs*, provides the initial reference for examining project assessment. See the [AIS proceedings record](https://aisel.aisnet.org/wi2024/12/).

Bhardwaj, Behl, and Pereira (2025), *Proposing an integrative data-analytics framework for micro, small and medium enterprises: a systematic review substantiated by evidence from two case studies*, is a related source identified for further reading. **Its full text has not yet been read.** Notes currently use the [publisher's abstract and bibliographic record](https://doi.org/10.1007/s10479-023-05186-9).

These starting sources do not establish that the proposed research gap is novel. A broader review must determine whether and how the project adds to existing work.
